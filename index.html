Admit One: The Five Task Verbs

IdentifyName the concept or the specific piece of evidence. One answer, no hedging.
DescribeTell what the process or outcome is, using details from the sources.
DetermineApply a rule to the sources and land on one specific result.
ExplainGive the reason and the evidence. Naming it is not explaining it.
WriteType a command with correct syntax that does exactly what was asked.

Midway Rules

  • Cite it: line number, rule number, file name, IP address.
  • One answer only. Two answers with one wrong earns zero.
  • Read the "Other than…" clause. It bans the easy answer.
  • "Modify a rule" means change an existing one, not add a new one.
  • Never leave a later part blank. Each part is scored on its own.
  • Pacing: 3 min read, 7 min skim, 35 min answer, 5 min review.
